# 4.8.1: lean managed execution

LPOS 4.8.1 is a patch on the 4.8.0 managed-execution release. It removes 4 ceremony skills (quality-router, system-auditor, test-evidence-auditor, acceptance-spec-reviewer) whose routing and audit ceremony did not improve correctness, and it fixes `source_snapshot` in managed execution to exclude generated artifacts, `public/`, `node_modules/`, `state/`, `.hermes/`, and `.lpos-managed/`. Hash-bound independent review now binds to real source files only, so reviews no longer fail on generated or vendored content.

All 4.8.0 controls remain: bounded exact-specialist execution in an exact Git worktree, risk-tier tool allowlists, preserved-receipt preflight, deterministic checks, strict machine-readable receipts, terminal capability gaps, and at most two consolidated correction cycles. This release does not publish, install, activate, deploy, or email as part of the local candidate build.
