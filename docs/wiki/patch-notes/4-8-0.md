# 4.8.0: managed execution

LPOS 4.8 adds `lpos managed-run`, a bounded local implementation path that runs one exact specialist in an exact Git worktree, preserves named prior receipts, applies a risk-tier tool allowlist, runs deterministic checks, and requires a different specialist to review the exact source and artifact hashes.

Capability gaps are terminal, correction cycles are capped at two, artifact paths cannot escape the managed worktree, and consequential execution remains separately gated. This release does not publish, install, activate, deploy, email, or run a paid-model canary as part of the local candidate build.
