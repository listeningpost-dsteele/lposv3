# 4.8.2: mandatory enforcement gates

LPOS 4.8.2 adds mandatory enforcement gates that move advisory rules into code that executes at choke points the agent cannot skip. Rules in prompts are suggestions; rules in code that runs are laws.

## What is new

Five gates:

1. **Pre-commit hook** (git): extracts visible text from changed HTML, runs anti-slop lint, runs tests, blocks commit on failure.
2. **Pre-deploy gate** (deploy script): re-runs lint and tests before deploy; checks for approval artifact. Independent of git; catches `--no-verify` bypasses.
3. **Process artifacts**: tier 2 and tier 3 changes require a signed approval artifact the agent cannot self-issue.
4. **Model separation**: creator and reviewer must be different model families. Same-model review is a mirror.
5. **Copy ownership**: the pre-commit lint is the gate; dirty copy never ships regardless of authorship.

Tiered enforcement prevents the over-correction death spiral:

- **Tier 1 trivial** (typo, CSS tweak, dep bump): lint and tests only.
- **Tier 2 standard** (new section, copy revision, bug fix): plus guild review and local approval.
- **Tier 3 material** (new page, pricing, brand): plus full review wave and explicit production approval.

The change determines the tier, not the agent.

## New CLI

```
lpos gate init /path/to/repo       # install hooks + deploy gate + config
lpos gate check /path/to/repo      # run the full gate check
lpos gate status /path/to/repo     # show gate installation health
lpos gate lint file1.html file2.md # run anti-slop lint on files
```

## What is preserved

All 4.8.1 managed-execution controls are unchanged:

- Bounded exact-specialist execution in an exact Git worktree
- Risk-tier tool allowlists
- Preserved-receipt preflight
- Deterministic checks and strict machine-readable receipts
- Hash-bound independent review
- At most two consolidated correction cycles
- Source-snapshot excludes generated artifacts, public/, node_modules/, state/, .hermes/, .lpos-managed/
- All prior authority, evidence, security, record-only external-action, and rollback controls
