# 4.6.0: verified continuity release

LPOS 4.6.0 republishes the complete, verified LPOS 4.5 operating system under the 4.6 release identity. It does not include Product Studio.

## What changed

- Release, package, installer, registry, workflow, evaluation, kernel, API, and documentation identities are synchronized at 4.6.0.
- The complete distribution was rebuilt and resealed from the verified 4.5 source lineage.
- The wiki and installation documentation now state the current inventory of 45 specialists, 29 Standing Operations, 70 benchmarks, and 22 schemas.

## What did not change

- No new runtime capability was added.
- Product Studio is excluded and deferred.
- Existing authority, review, evidence, security, Code Testing Guild, Continuous Operational Excellence, record-only external-action, and rollback controls are preserved.
