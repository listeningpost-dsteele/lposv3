# Application and Software Supply Chain Security Standard

Inspect exact source, interfaces, dependencies, build inputs, artifacts, and runtime paths. Trace untrusted input to privileged sinks. Verify authentication and authorization at the enforcement point. Test denial, malformed input, failure, retry, recovery, and object-level access.

Scanner output is supporting evidence, not a disposition. Dependency advisories require reachability and impact analysis. Build and artifact integrity must be bound to exact hashes.
