# Cloud and Infrastructure Security Standard

Inspect both authoritative infrastructure source and actual provider state. Define account, project, network, environment, control-plane, workload, secret, certificate, logging, drift, and administrative boundaries.

A plan is not applied state. A resource name is not effective policy. A managed-service label is not proof of security. Real access, denial, exposure, and control behavior must be exercised.
