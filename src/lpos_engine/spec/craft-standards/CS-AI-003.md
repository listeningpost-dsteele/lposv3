A material prompt or context change must include:

- authoritative source layers and precedence;
- exact compiled baseline and candidate hashes;
- diagnosed behavior failure;
- smallest source-level correction;
- conflict and duplication analysis;
- context provenance and disclosure authority;
- untrusted-content treatment;
- token budget, compression, and truncation policy;
- structured output and invalid-output recovery;
- representative and adversarial evaluation;
- regression comparison;
- model and provider assumptions;
- rollback.

Reject:

- prompt accretion;
- project facts embedded in universal roles;
- generic report output for unrelated professions;
- context dumping;
- hidden authority;
- retrieved content treated as instruction;
- testing only source fragments;
- portability claims without evidence;
- prompt changes approved from one favorable example.
