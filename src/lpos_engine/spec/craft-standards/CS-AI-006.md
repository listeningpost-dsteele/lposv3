Define:

- authoritative sources and access controls;
- parsing, normalization, deduplication, and versioning;
- task-appropriate units and chunking;
- retrieval and ranking methods;
- provenance and source revision;
- freshness, invalidation, and supersession;
- conflict and abstention behavior;
- tenant, Principal, project, and task isolation;
- memory write authority;
- memory class, scope, retention, correction, deletion, and promotion;
- representative and unauthorized-query evaluation.

Reject:

- indexing without a decision need;
- model inference stored as fact;
- citations that do not support claims;
- stale copies outranking authoritative sources;
- retrieval fluency as quality evidence;
- memory without correction or expiration;
- access filtering performed after retrieval.
