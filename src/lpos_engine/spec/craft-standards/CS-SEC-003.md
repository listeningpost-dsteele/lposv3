# Threat Modeling and Abuse Resistance Standard

Threat modeling must bind to an exact target and include assets, actors, capabilities, entry points, trust boundaries, data flows, misuse, abuse cases, compromised dependencies, attack paths, existing controls, control gaps, prioritization, uncertainty, and validation needs.

A framework category list is not a threat model. Every material scenario must have preconditions, path, affected assets, impact, and control implications.
