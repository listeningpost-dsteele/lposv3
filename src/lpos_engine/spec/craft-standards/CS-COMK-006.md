# Knowledge Architecture and Stewardship Standard

A knowledge system must make authoritative information identifiable, retrievable, understandable, governable, and maintainable.

Requirements:

- define users and knowledge jobs;
- inventory current objects, sources, owners, status, access, and lifecycle;
- establish one authority and explicit derivative surfaces;
- define object types, identifiers, status models, metadata, taxonomy, relationships, and provenance only where they support use or control;
- define access, privacy, confidentiality, and minimization;
- define ownership, review, supersession, archival, retention, and deletion;
- prefer linking and generation over copying;
- resolve duplication and conflict before migration;
- preserve audit history without presenting it as current truth;
- define integrity checks and rollback;
- and avoid systems more complex than the stewardship capacity.

Indexing everything is not a knowledge strategy.
