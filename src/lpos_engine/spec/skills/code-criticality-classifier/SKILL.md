# Code Criticality Classifier

Consider data sensitivity, permissions, financial movement, reversibility, blast radius,
API compatibility, migration risk, concurrency, production infrastructure, and customer
impact.

Return level, rationale, required gates, review authority, evidence required, and
conditions that would change the level.
